# MEmu Play — Keymapping Editor Research

Reference screenshot: `uploaded_media_0_1795685047044.jpg` (MEmu Play Free Fire keymapping editor).

## Editor Layout & Workflow
- **Right sidebar**:
  - Mode toggle at top: `Standard mode` vs `Smart mode` radio buttons.
  - Resolution/preset dropdown (`720P (Modified)`) with refresh/reset button.
  - Two tabs: `General` and `Advanced`.
  - `General` tab 2-column grid:
    1. `Joystick` (WASD 4-way circle)
    2. `Key` (Single tap spot)
    3. `Right-Click attack`
    4. `Multiple touches` (Repeated / multi-tap)
    5. `Skill attack` (MOBA skill cast)
    6. `Left-Click Attack` (Fire button)
    7. `Crosshair` (FPS aim / shooting mode toggle)
  - Bottom bar: `Keymapping switch (Alt+F1)` toggle, `Clear` button, `Save` button.
- **Canvas & Controls**:
  - Teal/cyan circular badges with white key labels (`Tab`, `Shift`, `Ctrl`, `Esc`, `Space`, `Alt`, `F2`, `M`, `R`, `Q`, `E`, `G`, `F`, etc.).
  - Inline edit pencil icon next to tap spots and crosshair.
  - Crosshair widget shows live vertical/horizontal sensitivity slider (`36%` readout) right beside the reticle.
  - Mouse-button icons (`Left-Click`, `Right-Click`) rendered with distinct mouse glyphs.

## Key Takeaways for ExR Player
- `Standard` vs `Smart` mode switch and global `Keymapping switch` hotkey.
- Clean 2-column icon palette with `General` and `Advanced` grouping.
- Inline opacity/sensitivity feedback and distinct mouse-button glyphs.

# Competitor Research Comparison — Android Emulator Keymapping

Based on observed reference UIs (MEmu Play, BlueStacks 5, LDPlayer) and documented features of NoxPlayer, MuMu Player, and GameLoop.

| Feature | BlueStacks 5 | MEmu Play | LDPlayer | NoxPlayer | MuMu Player | GameLoop |
|---|---|---|---|---|---|---|
| **Editor Layout** | Right 3-col palette, top Scheme + Gamepad tab, bottom Reset/Save | Right 2-col circular palette, Standard/Smart toggle, General/Advanced tabs | Right 4-col circular palette ("Drag icons to left"), top Cloud keymap + Scheme | Modular right sidebar, top scheme bar | Clean right drawer, cloud presets | Streamlined preset-driven |
| **Tap / Multi-Tap** | Tap spot, Repeated tap | Key, Multiple touches | Single click, Repeat tap | Single click, Multistrike | Tap spot, Repeated tap | Built-in |
| **Movement** | D-pad, MOBA D-pad | Joystick (WASD) | WASD D-pad | D-pad | D-pad, Right-click walking | WASD |
| **Aim / Shooting** | Aim, pan and shoot, Free look | Crosshair + Left-Click Attack | Aim (inline X/Y sliders) + Fire | View Control | Aim Key, Free Look, Fire | Smart Shooting mode |
| **MOBA / Skills** | MOBA Skill pad | Skill attack | Skill cast | Targeted Skill | Cast Spell | Built-in |
| **Gestures** | Swipe, Zoom, Scroll, Edge scroll | Swipe | Swipe | Two-finger pinch/pan | Slide, Zoom | Limited |
| **Macros / Scripts** | Script editor | Operation Recorder | Macro button | Script/Macro recorder | Text macro (`click`, `press`, `release`) | Restricted (anti-cheat) |
| **Gamepad** | Dedicated Gamepad tab | Supported | Supported | Supported | Left/right sticks | Supported |
| **Smart Context** | Smart scheme | Smart mode | Cloud keymap | Scheme switching | Smart schemes | Dynamic context switching |

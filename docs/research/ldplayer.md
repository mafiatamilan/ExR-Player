# LDPlayer — Keymap Settings Research

Reference screenshot: `uploaded_media_2_1795685047044.jpg` (LDPlayer Keymap settings).

## Editor Layout & Workflow
- **Top bar**: `Keymap settings` label, folder/import/export action, `Exit` button.
- **Right sidebar**:
  - `Cloud keymap` link and `Keymap scheme` dropdown (`Customize`, presets).
  - `Drag icons to the left side` 4-column icon grid (13 controls):
    - Single click (`A`), D-pad (`+`), Fire (`bullet`), Free Look (`eye`), Aim/Shooting View (`mouse+crosshair`), View Control (`360`), Skill Cast, Crosshair, Right-click Walk, Macro (`AA`), Rotate/Tilt, Quick Macro (`lightning`), Script (`scroll`).
  - Bottom checkboxes:
    - `Reduce inertia when moving with right button`
    - `Show the keymap prompt in games`
    - `Show keymap instruction when games start`
  - Action buttons: `Restore`, `Save`.
- **Canvas & Controls**:
  - Dark-blue circular/pill badges with cyan border, small `x` delete button at top-right and gear/edit icon at bottom-right.
  - FPS Aim widget (`Alt`) displays independent `X: 10%` and `Y: 10%` inline sliders directly around the badge.
  - Multi-key combos (`Alt+1`, `Alt+2`, `Alt+3`, `Middle mouse button`, `Right mouse button`) rendered as rounded pills.

## Key Takeaways for ExR Player
- Per-widget hover/corner delete (`x`) and edit buttons for fast cleanup.
- Modifier combo pills (`Alt+1`) and explicit mouse button labels.
- Independent X/Y sensitivity sliders on Aim widget + overlay visibility toggles.

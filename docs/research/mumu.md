# MuMu Player — Keymapping Research

Sources: Publicly documented MuMu Player keymapping documentation (mumuplayer.com).

## Editor Layout & Workflow
- Accessed via side toolbar Keyboard/Gamepad icon (`Alt+1` shortcut); right-clicking on the overlay opens the control palette.
- Top tab switcher between **Keyboard & Mouse** and **Gamepad** layouts.
- Duplicate key conflict detection highlights conflicting bindings in red before saving.
- Official game-specific scheme dropdown for instant profile switching.

## Control Types & Features
- **Tap Spot**: Fixed screen coordinate touch on key press.
- **Repeated Tap**: Rapid multi-tap at a fixed coordinate with configurable frequency/count.
- **Slide (Swipe)**: Directional swipe gesture path across the screen.
- **D-Pad**: Virtual joystick movement (`W/A/S/D` default) with adjustable radius and sensitivity.
- **Aim Key**: FPS camera/viewpoint mouse lock toggled via `F1` or `~`, paired with Left-Click **Fire/Attack**.
- **Free Look**: Independent camera inspection (`Alt` / `Shift`) without altering movement direction.
- **Cast Spell**: MOBA directional/cursor-targeted skill casting.
- **Zoom**: Multi-touch pinch-to-zoom via keys or mouse wheel.
- **Gamepad**: Left Joystick (movement), Right Joystick (camera/aim), and face/shoulder button mappings.

## Key Takeaways for ExR Player
- Conflict detection UI highlighting duplicate key bindings.
- Slide/Swipe control with configurable start, end, and duration.
- Separate Left/Right Gamepad stick mapping over touch zones.
